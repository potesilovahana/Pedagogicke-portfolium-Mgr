# Uživatelský návod

## Spuštění
1. Nainstalujte Python 3.10 nebo novější.
2. Nainstalujte Pygame příkazem `pip install -r requirements.txt` (Linux/macOS: `python3 -m pip install -r requirements.txt`).
3. Ve složce projektu spusťte `python main.py` (Linux/macOS případně `python3 main.py`).

## Procvičování
Zvolte režim sčítání, odčítání nebo kombinovaný režim. Odpověď zadejte klávesnicí a potvrďte Enterem. Lze použít desetinnou čárku i tečku. Další příklad otevřete Enterem nebo tlačítkem Pokračovat.

## Nastavení
Lze měnit hlasitost, celoobrazovkový režim, velikost písma a délku lekce. Nastavení se ukládá do `settings.json` vedle aplikace.

## Vlastní příklady
Do textových souborů ve složce `data` přidávejte příklady ve formátu `12,5+3,2=15,7` nebo `18,5-6,5=12`.
